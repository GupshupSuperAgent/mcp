# Changelog

Changes to the hosted Gupshup MCP server and to this repository. Versions match `server.json`.

## 1.0.0 (2026-09-30)
- First public release of the Gupshup Enterprise MCP (beta).
- **Apps:**
  - **Analytics:** 7 tools
  - **Templates:** 10 tools
  - **Campaigns:** 14 tools, plus the review-panel actions
- **Interactive review panels** for campaign launch, A/B tests and multilingual campaigns.
- 38 prompts.
- Setup guides for Claude, Claude Code, Cursor, VS Code, ChatGPT, Codex, Windsurf/Devin and generic clients.
- Claude Code plugin marketplace, and a `server.json` for the official MCP Registry.
