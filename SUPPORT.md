# Getting help

| You need… | Go to |
|---|---|
| Help connecting a client, or something in the docs is wrong | [Troubleshooting](docs/troubleshooting.md), then [open an issue](https://github.com/GupshupSuperAgent/mcp/issues/new/choose) |
| A new Gupshup account, early access, or pricing | [sales@gupshup.ai](mailto:sales@gupshup.ai) |
| Help with your specific account (credentials, channels, billing, template approvals) | Your Gupshup account manager |
| General Gupshup API docs | [docs.gupshup.io](https://docs.gupshup.io) |
| To report a security issue | [SECURITY.md](SECURITY.md). **Not a public issue.** |

Please never post passwords, tokens, phone numbers or customer data in issues.
